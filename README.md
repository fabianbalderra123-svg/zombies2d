# Noche de los Muertos — Zombie Survival

Juego web de supervivencia contra zombies en 2D, hecho con HTML, CSS y JavaScript (Canvas y Web Audio API, sin librerías externas).

## Cómo jugar
Abre `index.html` en el navegador.

- **W A S D** o flechas: moverse
- **Mouse**: apuntar
- **Click**: disparar
- **R**: recargar

Sobrevive oleadas de zombies cada vez más numerosas y rápidas. Los zombies morados son más resistentes y dan más puntos.
